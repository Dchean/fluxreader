# UI 契约：REQ-006 文案统一 + REQ-008 控件一致性收尾（TASK-041）

## 范围与冻结项

- 沿用现有 UI：不改布局结构、不改信息层级、不引入新组件库或新依赖。
- 只改**字符串**与**控件的视觉一致性**（焦点可见性、尺寸、布尔控件外观）。
- **不得改变任何行为**：点击后的动作、跳转目标、计数口径、状态流转全部保持原样。

## 必须覆盖的状态（ui_checks）

1. 主视图：时间线卡片（列表/画廊/社交/通知四种布局）、工具栏、侧栏（视图筛选与订阅树）
2. 阅读器：正文区、AI 区块、文章操作按钮行
3. 设置页：各分区标签与说明文字、连接与同步区、危险操作确认
4. 覆盖层：搜索、命令面板、右键菜单、灯箱、对话框
5. 空状态与错误提示（含 toast），以及演示模式/无服务时的提示

## 验收要点（逐条可核）

- 同一动作在全应用只用一套说法：标为已读/未读、查看原文、刷新、显示全文
- 标点统一：省略号一律 `…`（U+2026），冒号一律 `：`；不得再出现 `...` 或 ASCII `:`
- 演示模式 / 无服务能力的提示统一前缀
- 删除括号堆叠与解释性尾巴，保留必要信息；不新增感叹号（当前全仓为 0 个，应保持）
- 焦点可见：所有可交互控件（按钮、输入框、文本域、图标按钮、开关）都有可见的 focus-visible 指示
- 布尔控件统一：同类开/关语义使用同一控件与视觉（当前设置页用 Switch，AI 相关用原生 checkbox）
- 图标按钮尺寸与内边距收敛到一组取值；同类主按钮样式统一到一个类

## 需要提交的证据（放在 .workflow-kit/tasks/evidence/ 下）

- 截图 PNG：主视图、设置页、覆盖层至少各一张
- 核对报告 MD：逐条列出「文件:行 → 原文 → 改后」的映射，以及控件一致性的具体变更
- 诚实声明：静帧截图无法证明焦点可达性与动态效果，报告中需说明焦点与交互的核对方式（例如实际用键盘 Tab 遍历观察），不得用截图冒充动态证据

## 限制与不适用

- 本项目为桌面单平台，无多设备目标
- 本任务**不做**转场/动画改动（动画属 REQ-005，见 TASK-042），仅静态视觉与文案
- 不改 `tools/frontend-regression.mjs` 的既有断言语义（该套件不断言中文串）

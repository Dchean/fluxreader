# UI 契约：TASK-101 设置页文案精简与 Fever 提示（2 条 ui_checks）

基线：dev@a5598cb（v0.16.0 后）。本契约约定本卡 UI 改动后「必须为真」的可核对状态。
取证方式：tmp/audit-r3/harness（Chrome CDP + 忠实假后端），设置页截图 + DOM 文案断言。

## V1.sync-hint-concise

设置页（SyncTab 为准，其余设置页同样适用）提示文案满足：
- 不再出现原长句「只验证连通性（秒级）」与「会立即在后台拉取订阅与文章状态。已读/收藏等变更约1秒内推送到服务端」整段；
- 新文案为短句（单句 ≤40 字或两条要点），且保留三个关键语义，DOM 断言可核对：
  a. 「测试连接」仅验证登录/连通，不拉数据；
  b. 「保存并同步」才开始拉取订阅与文章；
  c. 断开连接会删除（移除）同步拉取的内容。
- 已读/收藏回传语义若在新文案中保留则校验其存在；若被精简掉，progress 中说明取舍理由。

## V2.fever-api-password-hint

- 选择 Fever 协议的连接表单区域存在一行简短提示，含「API 密码」字样，
  说明 FreshRSS 的 Fever（与 GReader）均使用个人设置中的 API 密码；
- 提示为单行短句（≤50 字），不出现多分号长链。

## 明确不做（本契约范围外）

主界面卡片/阅读器文案（REQ-006 已在历轮收口）；GReader 协议行为与文案结构。

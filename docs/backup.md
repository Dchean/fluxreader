# 数据库备份与恢复边界

FluxReader 的全部订阅、文章正文、读藏状态与设置都在本机 SQLite。OPML 与配置
同步只覆盖订阅/设置的一部分，不能替代完整数据库备份。

## 自动快照

- 数据库 schema 升级前，`db::open` 会先创建完整快照，再执行迁移。快照经
  `VACUUM INTO` 生成，包含 WAL 中尚未 checkpoint 的已提交数据；不会直接复制
  主库文件。
- 配置同步的镜像模式将删除本地源或分类时，预览与确认阶段会创建删除前快照；
  预览文件用于确认卡提示。确认应用时会在持有数据库锁、开始删除事务前重新
  创建并验证本次快照，包含预览后新写入的正文与 AI 产物。新快照创建失败会
  阻止镜像删除；已有预览文件不能代替本次快照。应用回执显示本次快照路径。
- 快照位于应用数据目录的 `backups/`（例如
  `%APPDATA%\com.fluxreader.app\backups\`）。文件名包含类型、from/to schema
  版本与 UTC 时间。
- 迁移前快照与镜像删除前快照各保留最近 10 份；手动创建的备份不参与自动清理。
  清理按合法生成名中的 UTC、数值序号与 PID 排序，schema 版本不参与时间排序；
  本次快照始终保留，即使系统时间回拨也不会被清理掉。只有字段、日期均有效的
  完整自动快照名且文件类型为普通文件时才参与清理，未知命名、`.partial`、
  目录与符号链接均保持原状。
- 迁移前快照失败不会阻止正常启动，但会记录错误并在启动后显示可见警告。迁移
  自身失败时，错误文案会给出对应的 `backups/` 快照文件名。

## 手动备份

设置 → 关于 → 数据备份 → 「创建数据库备份」会创建当前数据库的完整快照，并
显示路径、schema 版本与大小。成功后可「在文件夹中显示」。

备份包含：

- 订阅源、分类、文章与正文；
- 已读/收藏状态、同步队列与 AI 缓存；
- DPAPI 加密后的凭据密文（仅当前 Windows 用户可解密）。

备份文件按应用数据目录的默认用户 ACL 保存，不额外加密。请按用户私有数据保护，
不要上传到公共位置或跨 Windows 账户分发。

## 恢复（应用外手动操作）

应用不提供覆盖式 restore；恢复必须完全退出 FluxReader（包括托盘）后手动替换：

1. 关闭 FluxReader，确认托盘图标也已退出。
2. 在 `%APPDATA%\com.fluxreader.app\` 中保留一份当前现场，随后把选定备份复制为
   `fluxreader.db`。
3. 删除同目录下的 `fluxreader.db-wal` 与 `fluxreader.db-shm`（若存在），避免旧
   WAL 覆盖新文件。
4. 重新启动 FluxReader。

若备份来自另一 Windows 用户或另一台机器，DPAPI 密文凭据无法解密，需要重新输入
同步与 AI 凭据。恢复前建议先复制当前数据库再操作，应用不提供提交后的自动撤销。

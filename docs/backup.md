# 便携备份、同步与本机恢复

订阅、读藏与正文保存在当前 Windows 用户的本机 SQLite。换机使用设置 → 关于 → **便携备份与换机**；纯本地多设备持续同步使用设置 → 同步 → **本地资料库 · WebDAV**。OPML 仅用于订阅列表交换。

本页描述当前前后端职责与实际边界；仍未闭合的真实 WebDAV、原生文件选择器、跨机与规模验证见 [roadmap](roadmap.md)。

## 当前数据空间

2026-11-09 重构使用独立 `fluxreader-v2.db` 数据空间，格式由 application_id `1179796018`、schema version `1` 和当前必需结构共同识别。原 `fluxreader.db` 及其 `-wal`/`-shm` 原样保留，不自动迁移、不删除；首次发现旧库时新版进入新空间并提示旧文件保留位置。

新格式只初始化当前结构；缺少必需结构的早期试验格式也不自动升级。误把旧格式文件放到新空间时，打开入口先只读检查并明确拒绝，拒绝发生在 WAL、凭据或 schema 写入之前。旧数据与旧备份不属于兼容范围。

## 便携备份（.flxb v4）

从任意 RSS/WebDAV/纯本地模式导出，包含订阅、分类、普通设置、读藏状态及可用的未读/收藏正文，也保留已退订来源的收藏。凭据、AI 服务配置与产物、机器身份与发送队列不进入便携文件；同步/便携可见范围由 `db/settings.rs` 定义（见[契约单点](contracts.md)的设置名与值域）。缺少的正文单独计数，不伪造完整正文。文件未做口令加密，属于用户私有资料。

v4 按头、分类、源、文章及唯一内容记录逐块编码，验证每块与完整容器摘要；格式单点为 `local_sync/backup.rs`。RSS 来源收藏不套用 WebDAV 的本地源过滤；同一内容被多条文章或 primary/RSS 引用时只写一份。缺少已经引用的正文块是损坏，不能当作声明缺正文后继续成功。旧配置快照和旧便携 v3 明确拒绝，不自动迁移；备份保存正文及媒体引用，不承诺永久镜像所有图片/音频二进制。

- **导出**：以 WAL 读快照为截止点，之后提交的前台写入不进入文件；目标文件以 `create_new` 打开，已有文件不会被覆盖。远端状态候选仍在折叠应用时先等其收敛（上限 300 秒），超时以“远端状态正在应用到本地，请稍后重试便携导出”失败。结果给出文件路径与收藏、缺正文数量。
- **预览校验**：只读打开（Windows 上拒绝其他写入/删除共享），验证完整文件及正文引用，不修改资料库；取消选择或预览不恢复数据。
- **确认后替换**：恢复必须携带与已审阅预览相同的摘要，校验与解析同一输入；数据在一个事务内替换，分类/源/文章新 ID 高于旧库持久高水位（含已删除行），本机同步身份重新生成。校验、文件变化或事务失败时原资料库保持可读，需重新预览。恢复会断开 RSS 与 WebDAV，AI 服务和全部凭据须重新输入；本机开机启动/关闭提示保留，非敏感 `syncMode` 偏好可恢复。
- **退出拒绝**：应用退出过程中，导出、预览、恢复三个入口直接拒绝（“应用正在退出，备份未开始/预览未开始/恢复未开始”），不进入写路径。
- **成功**：导出完成并同步文件后，目标是可预览、可恢复的完整 v4 备份。
- **普通返回失败**：只有本次 `create_new` 成功创建的目标会参与清理；若它不是完整且可预览的 v4 文件，返回错误时会尝试删除该目标，但清理自身失败时仍可能残留。路径、权限或创建失败不会清理任何文件；已有目标因 `create_new` 被拒绝时内容保持原样。完整文件同步成功后若事务提交报错，仍保留可预览的 v4 文件。
- **取消与同名拒绝**：文件选择取消发生在导出开始前，不创建目标。目标已存在时导出拒绝覆盖，不改变原文件。
- **进程中止**：强制结束进程或断电时不能保证执行返回错误清理；目标可能留下不完整文件，因 `create_new` 同名重试会被拒绝。先通过预览确认文件状态，再自行选择处理方式；恢复失败只回滚本机数据事务，不动已有备份文件。

恢复期间界面处于明确忙态，既有设置、AI 配置、读藏、封面上报和播放记录写入先结清，图片请求暂停且旧灯箱请求失效，新的用户编辑暂时不可用；提交与回滚语义见上。前端清除旧选择、阅读位置、正文/AI/播放缓存，回读设置、RSS/WebDAV 状态和新数据。

“资料库恢复已完成，但界面刷新失败”表示数据事务已提交。此时只使用“重试界面刷新”，不会再次替换资料库。普通 WebDAV 后台数据刷新仍保留当前阅读成员和位置，不调用恢复专用的重建入口。

## WebDAV 持续同步

仅纯本地模式可以连接 WebDAV；RSS 同步服务与 WebDAV 不能同时成为读藏状态权威。同步范围、独立读藏合并方向与协议边界见[同步兼容矩阵](sync-compat-matrix.md)的纯本地 WebDAV 段；可选实时或定时同步（间隔 1–1440 分钟，由 `local_sync/runtime.rs` 校验），并可手动“现在同步”。

“已配置连接”只说明已保存连接；“状态同步确认”“正文同步确认”分别显示后端的确认时间。本机待补正文数不是上传进度；待处理状态/待确认批次与下一重试时间分别显示。状态轮次完成不代表正文已全部到达。错误不会擦除当前可读资料，断开也保留本地数据。

远端物理删除当前关闭，容量与远端空间治理的缺口见 [roadmap](roadmap.md#sync-correctness)。正文保留的判定与释放见[契约单点](contracts.md)的「正文保留与释放（本机）」行（本机保留期 0 为永久、上限 3650 天，未读/收藏、队项与实际 hold 继续保护）。本页只保留与备份相关的边界：SQLite 故障快照保留本机年龄，便携格式不传年龄，恢复按本机时间重新开始。

旧 Gist、GitHub 同步授权与手动配置快照前后端已退役。GitHub Releases 更新检查仍保留。

## 本机故障快照（高级）

设置 → 关于 → **本机故障恢复（高级）** 中保留“创建数据库备份”。它生成当前数据库的完整 SQLite 快照，包含正文、同步队列、AI 缓存和 DPAPI 密文凭据，只适合当前 Windows 用户的本机故障恢复，不作为换机入口。

快照使用 `VACUUM INTO` 读取 WAL 中已提交数据，生成自包含文件，校验后交付。位置为 `%APPDATA%\com.fluxreader.app\backups\`；手动快照不自动清理。历史迁移/配置镜像文件按其原规则保留，新数据空间不再执行旧升级和镜像配置流程。决定与历史证据见[数据库快照决定](../.agents/notes/implemented/architecture/2026-11-05-数据库快照与恢复边界.md)。

本机快照的恢复仍在应用外进行：完全退出 FluxReader 和托盘，保留当前现场后将选定自包含快照复制为 `fluxreader-v2.db`，并移除同目录当前 `fluxreader-v2.db-wal` / `fluxreader-v2.db-shm` 旁文件，再启动验证。跨 Windows 用户/机器不能复用 DPAPI 凭据；便携换机请使用上面的 `.flxb` 流程。

不能分别复制运行中的主库/WAL/SHM 来冒充一致快照，也不能以文件哈希或 `quick_check` 代替恢复后的功能验证。真实原生选择器、跨机器与断电恢复需各自环境证据。

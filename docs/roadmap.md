## 二、AI、配置与回归维护

以下保留历史发现编号，方便回查，不表示 2026-10-19 的整张审计表仍未修复。同步条目三态与 ACK 已由[状态写回验证](../.agents/notes/implemented/bug-fix/2026-11-03-状态写回ACK验证与条目三态.md)收口；GR 晚到未读回补、普通 contents ID 覆盖与过期意图恢复见[当前决定](../.agents/notes/implemented/bug-fix/2026-11-05-GR权威集合回补与过期意图恢复.md)。这些不再列为待办。

| 编号 | 领域 | 问题 | 影响 |
| --- | --- | --- | --- |
| B-P2-1 | AI/配置 | 正文修订或全文提取后 `aiStatusById` 不失效 | 旧 AI 产物仍显示「完整」，与实际正文不匹配 |
| B-P2-2 | AI/配置 | 卡片 partial 在重启后不可达 | 重启后只有片段、没有整篇产物的条目不再取校验状态，用户必须打开阅读器才能看到 partial |
| B-P2-3 | AI/配置 | `cache_cleanup(scope='ai')` 对仅片段条目不推进 epoch | 批量清理后，仍在途的旧请求可以写回片段或整篇产物 |
| B-P2-4 | AI/配置 | 配置快照重复分类名静默歧义 | 同名不同 `sync_id` 的分类对象级折叠已由 OPT-010 修复（身份优先匹配、重复 sync_id 拒收）；但快照 `FeedSpec.folder` 只携带名称，feed 归属仍按名折叠——第二个同名分类被新建却收不到源，预览无法分辨（2026-11-01 复核：原「合并到第一个」的机制描述已过时，残余后果仍成立，根因是快照格式） |
| B-P2-5 | AI/配置 | AI 校验状态请求没有代次守卫 | 清除或新生成之后返回的旧回包可覆盖新状态，重新显示 partial/stale/complete |
| C-P2-3 | UI/性能 | 同一 URL 的后续条目在扫描窗/批次外被负缓存跳过 | 指向同一 URL 的其它条目在本进程内不再补封面，只有重启或缓存逐出后才可能重试 |
| C-P2-4 | 测试/文档 | act 警告降为计数后没有阈值与按用例归属 | 真实的 act 外更新、定时器泄漏或卸载后更新可以静默通过，回归不可归因 |

AI 配置变更后，显示层 `aiStatusById` 也不会立即失效；动作时仍有后端权威复核。单一产物清除会推进共享 `ai_epoch`，连带拒绝另一产物的在途提交，属于保守但较宽的失效边界。`folders.name` 仍无 UNIQUE 约束；OPML 同名复用与手工同名拒绝已实现，但存量重名目录、配置快照按名称关联 feed 的歧义尚需独立数据策略。

## 三、证据边界与未完成验收

- **真实 WebView 性能测量缺口**：OPT-017 的基线是隔离 SQLite、jsdom 与组件回归。2026-11-05 真实 headless Edge 已覆盖延迟自然比例图片、两视口四波固定锚漂移 0px，见[画廊有界渲染](../.agents/notes/implemented/feature/2026-10-16-画廊有界渲染.md)；它证明该受测场景的几何稳定，不证明真实 WebView2 的滚动帧率、解码耗时、任意真实库高度分布或性能收益，50ms 判定线仍无当前实机数据。
- **OPT-015Q 用户实机复测未完成**：用户曾在 `v0.17.1` 观察到窗口「先居中再跳」；隔离驱动在 dev 的生产自动建窗路径未复现，生产代码零改动。用户尚未在包含窗口恢复修复的构建上复测，构建归属未证实。
- **OPT-015N 的场景边界**：八个原生窗口场景只覆盖固定双屏 3840×2160、1.5 缩放；物理拔屏、动态 DPI 切换与完整 SMTC 媒体键整链不在证明范围内。
- **AboutTab 更新检查的真实组件点击未覆盖**：现有证据是 Rust 本地 HTTP 单测、`compareVersions` 纯函数单测与源级接线；真实点击 → 提示的整链没有组件回归（用例因 Node 22 的 act 调度不稳定已撤回）。
- **服务端 × 版本兼容未实机验收**：兼容矩阵的「已验证」列只覆盖测试替身与严格夹具，不代表任何具体部署版本；真实 Miniflux / FreshRSS 未逐一实机验收。
- **主页面导航与媒体的实机边界**：完成态译文链接代理、精确 origin 导航钩子及 CSP 已实现并经独立审计；验证来自组件事件、实际插件回调的 mock runtime 与净化测试。未启动已安装 Tauri 验证真实点击或全部第三方播放器，见[主页面导航与外链边界](../.agents/notes/implemented/architecture/2026-11-05-主页面导航与外链边界.md)。
- **存量 identity 惰性收敛**：identity 重算与等价合并只对触达行生效，未触达的旧行不会一次性回填；收敛随读取/写入逐步发生。
- **NotifCard #185 待观察**：浏览器 mock 模式下点「通知」布局曾崩溃渲染树（`getSnapshot should be cached` → React #185），后续复现尝试全部阴性；真机 Tauri 下是否复现尚未验证。测量电池与实机清单在存档分支。**2026-11-01 W4 起主线常驻产品树 ErrorBoundary**（`componentDidCatch` 记 error + componentStack）——实机复发时归因所需的 componentStack 已有捕获点，不再需要先补钩子；见 [.agents/notes/implemented/architecture/2026-11-01-产品树错误边界放顶层.md](../.agents/notes/implemented/architecture/2026-11-01-产品树错误边界放顶层.md)。

## 四、已评估并明确不修的边界

以下是明确的产品或兼容边界，改动它们需要新的决定：

- **流式翻译的 delta 不逐段净化**。逐 delta 过 sanitizer 可能切断跨 delta 的 HTML 标签；当前流式阶段使用 React 纯文本插值，完成后回读净化 HTML。脚本继承 `default-src 'self' ipc: http://ipc.localhost`；`object-src`、`base-uri`、`form-action` 显式为 `'none'`。iframe 仍允许 HTTP/HTTPS 来源，并受正文净化域名名单限制；主 frame 由独立精确 origin 导航策略约束，不能把 CSP 概括为“所有内容仅本地”。
- **旧二进制的订阅标题改名不兼容**。v34 只保留插入触发器兼容旧二进制新增源；`UPDATE feeds SET title=...` 与旧刷新路径共用列，无法区分用户改名与抓取标题，因此不新增 UPDATE 触发器。升级后旧客户端写入的标题可能在下一次新客户端刷新时被覆盖。
- **自定义标题没有清除入口**。编辑源名会写入 `title_custom`，把名称改回源站当前标题也不会恢复“跟随抓取标题”；目前只能直接修正数据，专用重置入口尚未提供。
- **不做应用内覆盖式数据库恢复**。迁移/镜像/手动快照已落地，但恢复仍要求退出应用后替换主库并移除 WAL/SHM；应用内原子交换、重启与确认门未实现，边界见 [backup.md](backup.md)。
- **跨账号不迁移未确认意图**。断开/换号清除状态队列，直连读/藏数值仍保留；当前确认界面已说明它们不会自动补推到新账号。订阅 outbox 的断开/同身份重连与跨身份放弃政策另见[生命周期终点](../.agents/notes/implemented/bug-fix/2026-11-02-订阅outbox生命周期终点.md)，在途创建的远端孤儿订阅仍可能需用户手工清理。
- **恢复过期意图不创造远端身份**。显式恢复按当前本地目标与当前账号代际重新入队，无身份项仍区分仅本机/等待绑定；缺文章继续保留过期。远端已删除正文或 feed 元数据消失的孤儿历史无法凭本地猜测恢复。

## 六、产品语义待确认

## 七、其余明确保留的技术边界

历史收敛清单见[审计修复收敛路线](../.agents/notes/implemented/process/2026-10-31-审计修复收敛路线.md)。以下未纳入本轮有限收口；它们不是本轮新增审批条件：

- **性能**：同步端到端耗时基线缺失（需真实账号并单独约定读写边界）；Fever 空正文条目每轮 with_ids 重拉一次（回补记账候选）；F1 计数绝对耗时跨 SQLite 构建不可比（查询计划形态已由 CI 断言锁定）。

- **协议残留**：Fever 兼容旧 toggle 的探测→mark 之间无条件写原语，仍存在多设备并发窗口；GR light 维持 read-wins，已读未收藏晚到旧文仍依赖 full。权威集合的语义性漏报不能靠分页完整性识别，详见兼容矩阵。迁移 v31 清洗本身仍无独立专属回归；v31→v32 分类测试不等于该清洗迁移已单独覆盖。

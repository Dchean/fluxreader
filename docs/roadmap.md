## 同步正确性

| 问题 | 当前结果与限定 |
| --- | --- |
| 断开后 Fever 内部仍发后续请求（SYNC-01） | 外层会话守卫未覆盖同一高层调用中的逐 ID 写入和探测→写边界；已发请求不能撤回，断开后的新请求需要阻断 |
| 无链接条目被丢弃（SYNC-02） | 两协议不同远端 ID 的空/缺/空白 URL 条目未入库，Fever 历史还会记完成；正常 URL 对照可入库 |
| 同步回执与提交事实分离（SYNC-03/05/06） | 重认证成功可能丢首轮已提交变化标记；出队确认失败、Fever 完成时间写失败未进入报告。故障注入已证，不等于意图已被删除 |
| 缺归属的新 GR 条目静默跳过（SYNC-04） | 不完整响应缺 origin 时不入库而游标前进；修正响应后 light 仍可能漏，full 可补。真实部署此响应频率未测 |
| 订阅弱 URL 身份覆盖稳定远端 ID（S7/S8） | 同 ID 改 URL 会删旧建新并丢本地布局，服务端仍保留的文章可由 full 回补；不同 ID 仅 HTTP/HTTPS 差异也可能合并绑定。固定 Miniflux 源码支持该输入形态，具体部署未实机验证 |
| 真实服务端状态与完整性边界 | GR light 保持 read-wins；已读未收藏晚到旧文仍依赖 full。格式完整但语义漏报的权威集合无法由分页守卫识别；详见[兼容矩阵](sync-compat-matrix.md) |

## 未完成验证与条件风险

- **启动接手时序（NF4）**：受控 `get_setting` 回包延迟下，后台刷新接手后出现实际有 501 未读、UI 显示空态；手动加载可恢复。共享 DB Mutex 不允许把该探针解释为慢 SQL 持锁时被列表超车，原生 IPC 触发可达性未验证，未计确证产品缺陷。
- **真实部署**：FreshRSS/Miniflux 服务端×协议×版本没有逐一实机验收；真实 WebDAV/Gist、跨设备配置、7 个 ignored live 测试未覆盖。
- **原生系统集成**：安装版 WebView2 IPC/解码、托盘、通知投递/点击、自启登录、SMTC 与多屏 DPI 未完成本次实机验收。旧窗口驱动仅覆盖固定双屏 3840×2160、1.5 缩放；物理拔屏/动态 DPI 与用户冷启跳位复测仍缺。
- **性能**：真实库同步耗时、当前 WebView2 长会话与滚动 p95 未测。短时开发浏览器 rAF 和历史 SQLite 数字不填补这些空缺。
- **测试维护**：AboutTab 更新检查的真实组件点击链未覆盖；act warning 只有计数而无按用例归属/阈值（C-P2-4）；部分设置异步路径无统一卸载守卫；迁移 v31 清洗无独立专属回归。
- **待观察崩溃**：旧浏览器 NotifCard 曾出现 React #185，后续反例阴性；已有 ErrorBoundary 捕获 error/componentStack，复发时应保留现场，不按旧观察宣称当前必崩。

<a id="accepted-tradeoffs"></a>
## 仍保留的产品与兼容取舍

- GR light 的 read-wins、标读向同文副本广播而未读/收藏只当前绑定，仍是既有客户端政策；跨源传播是否改为布局隔离尚待产品决定。
- Fever 历史 toggle 兼容的探测→mark 没有服务端条件写保证，保留多设备并发窗口；空正文条目可能每轮 with_ids 重拉。
- GR 退订 400/404 容忍可能清队但远端仍在；本机墓碑阻复活，不能把清队当远端确已消失。改变取舍前要确定读回与重试成本。
- 配置镜像只改本机订阅/设置，删除不产生远端退订；连接建议不直接激活凭据或旧绑定。恢复配置不等于恢复原账号阅读状态。
- 跨账号不迁移未确认意图；断开保留的直连读/藏不会自动补推新账号。显式恢复过期意图只按现有身份重建，不创造远端目标。
- 不提供应用内覆盖式数据库恢复；退出后手动恢复的边界见[备份说明](backup.md)。
- 流式译文以纯文本显示，完成后回读净化 HTML；不逐 delta 解析可能被截开的标签。无 src 的 data-src 图片和协议相对 iframe 仍是当前兼容边界。
- 社交短文固定正文区与按钮槽为异步水合稳定性取舍；紧凑化须重新验证媒体加载和锚。
- 旧二进制订阅改名没有 UPDATE 兼容触发器；自定义标题没有“恢复跟随源站标题”入口。存量内容 identity 仅触达时惰性收敛。
- 旧版断开未留下账号见证的间隙无法回溯；订阅发送确认与后继链重定之间进程终止仍有恢复上限。

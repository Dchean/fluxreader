## 交付

1. tools/frontend-regression.mjs分为独立领域文件与公共harness，原每条行为断言可追溯；门禁聚合任意失败为非0，不能错误并行共享store导致互相覆盖。保持两种测试loader仅一份实现，移除过时自我比较注释。
2. 增加真实挂载测试通道，选择最小dev依赖（jsdom/happy-dom+React act或现有浏览器方案比较后Note），覆盖effect生命周期：快速五布局切换、body cache invalidate、autoAI开关、Reader源码切回和closeAsk；捕获componentStack，不能只SSR。
3. Node主版本与CI一致；更新source-map-js>=1.2.2间接依赖并重审，不盲目npm audit fix跨major；npm ci/lint/build/frontend全过，确认prod打包无开发依赖风险夸大。
4. Rust fmt/clippy/test各自有承担者：CI步骤不能因为fmt失败就完全不执行后续诊断，同时job任一失败仍红。使用if: success() || failure()等明确策略，不continue-on-error掩盖失败。tag/v*触发CI或明确workflow_dispatch补发解决release等待不存在run，避免重复发布。
5. ingestion_e2e/scheduler_e2e的本地HTTP fixture自托管化或CI明确启动/关闭服务，受控ignored套件真实执行；live测试仍不默认全include-ignored，不访问实际账号。
6. 同步更新AGENTS/README/测试Note：本机已能cargo，保留Windows生产路径CI，不把Linux降级路径当主要Rust验证。

# Agent Note: 查询与分页契约

Status: implemented

## Problem

用极大 limit 假装全库、不稳定集合上的 OFFSET、只按查询参数识别旧请求，曾分别造成旧文章不可达、标读/取消收藏后的跨页漏项和 A→B→A 迟到覆盖。显示去重、搜索、计数、批量操作若各自造范围，又会使“看到的集合”与“操作的集合”无法解释。

## Decision

`QueryScope` 单点派生 args、markScope、pageKey、viewKey；请求记录 scope/layout/sort，响应只有仍属于该查询实例才接受。缓存键现有字符串形态有兼容消费者，改变它们须连同缓存与筛选契约验证。

分页采用 `(published_at, id)` keyset，谓词必须与 ORDER BY 同列、同方向；例如 DESC 使用 `a.published_at < ? OR (a.published_at = ? AND a.id < ?)`。时间为存储层统一口径的 TEXT，比较使用与排序一致的裸列，外部游标只走绑定参数。两个游标参数必须成对，兼容入口缺一项会回落 OFFSET；索引 `idx_articles_published_id` 支持该次序。日期规范化与时区边界另见[时间口径](../bug-fix/2026-09-23-时间比较与时区口径.md)，不能把任意时区字符串的字典序当统一时间序。

续页沿用首页 serial，不自行开启新实例；游标按后端实际返回推进，是否满页决定 exhausted，不能按去重后的显示行猜结束。后台刷新重建已加载窗口，围绕目标 keyset 续拉，并用 `ceil(target / ARTICLES_PAGE_SIZE) + 1` 限制异常循环；固定首页 500 行不能覆盖深页锚点。

### 集合与回执

- 智能去重在 SQL 的当前 scope×视图内选同 `url_norm` 最小 id 代表，不在分页后滤数组。单源/布局、未读/收藏/今天和计数/锚定必须共用同构谓词。搜索在关键词匹配集合内选代表，不能让不含词的小 id 隐藏含词副本。
- 搜索 trigram 只是 ≥3 字符的候选加速，LIKE 才裁决匹配；短词、索引缺失或 MATCH 失败回落 LIKE。它不改变顺序、去重或字段语义。
- 显示去重不缩小“全部已读”的操作集合。markAll 冻结范围未读与同组读闭包，读值、字段版本、队列同事务；unread/star 不广播。搜索锚定缺位置可按 id 注入详情并打开 Reader，注入不推进分页游标，也不伪造当前布局卡片。
- `set_read/set_read_bulk` 返回真实翻转行，markAll 返回实际影响数。回执是请求时的提交事实，不是当前状态：`applyReadReceipt` 按行×字段写序号识别较新 unread，仅对实际接受的行改变状态/计数，窗口外兄弟与视图缓存同口径，无关行的新操作不使整批回执失效。

### 读取与计数提交

`counts_snapshot` 在同一数据库锁内返回源计数和范围计数。源计数保留布局无关底座；scopeCounts 带 layout/dedup，选择器只消费两者均匹配的快照。空聚合必须 COALESCE 为四个零值，前端默认值不能掩盖 SQL NULL 错误。

reload 与写后对账共用读取序号、写前沿和在途写引用计数。计数只在仍是最新读取、发起后的写前沿未推进且没有未提交意图时落地；读取失败保留同 scope 已确认值。全部写落定后由对账收敛，不能以逐条 ±1 代替折叠组真实计数。

条目快照也记录发起时写前沿与在途行×字段集合。较新本地写保留本地值；读取时已在途的乐观值也受保护，保护本身不推进版本，以便失败还能回滚。若快照值已等于本地值，则按已落定声明推进版本，迟到失败不得推翻已接受事实。未受保护字段照常读取，新鲜读取仍可接受外部变化，本地不是永久权威。

app_settings 的读取单飞凭据绑定发起时写序号、应用代次和读取序号，不能把跨提交的旧在途读 join 成新鲜结果。bootstrap 先等待捕获时写前沿；发现旧读则新读，应用回读强制新鲜。完整“确认基线 + 待写意图投影 + 应用屏障”归[内容身份篇的设置协议](2026-10-12-订阅条目与共享内容身份.md#设置快照的独立提交协议)，此处只规定共享读取与旧响应接受条件。

## Alternatives considered

- **保存完整快照 ID 序列**：可以冻结集合，但需写快照表、失效与回访生命周期；现有时间+id 全序让 keyset 更轻。
- **OFFSET 客户端补偿**：客户端不知道并发同步移除了多少行，补偿只能猜；集合定位应由 SQL 谓词成立。
- **每个续页推进代际**：会把同一查询中的首页/续页互相作废；代际归查询实例，非每个网络包。
- **日期函数排序**：若表达式与索引不匹配会退回扫描/临时排序；含 localtime 等非确定性修饰的表达式也不能依赖确定性索引。先统一存储口径并保持谓词同构。
- **分页后去重或用显示代表执行 markAll**：前者破坏满页/游标，后者遗漏隐藏副本；显示与操作必须明确各自集合。

## Consequences

契约减少了快照与写回相互覆盖，但增加 serial、写前沿、在途集合和缓存同步成本。新增排序需要匹配的谓词和索引，缺半个游标的兼容回落会静默变慢。回滚版本不包含已确认基线，不能由这些读取守卫推出连续失败正确，见[乐观写入边界](2026-10-05-乐观写入的版本守卫.md)。

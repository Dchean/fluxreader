# Agent Note: 同步冲突政策单点

Status: implemented

## Problem

Google Reader 与 Fever 的读状态和星标权威方向不同。规则散落在协议分支时，维护者必须跟完整条链才能知道何时允许远端覆盖本地；把数据库错误折成零行又会使“失败”与“无变化”在同步报告中不可区分。

## Decision

2026-10-07至11-08的历史选择是GR单向read-wins及跨源read广播，理由是避免历史未读成批恢复；2026-11-09用户明确选择源间独立与远端重新未读可返回，后继为[源内等价组与持久状态](../../../../docs/architecture.md)。本篇的字段版本、失败关闭及提交信号约束继续有效。

`sync/conflict_policy.rs` 保存四格政策，行级应用返回 `AppResult<usize>`：

| 协议 | 读状态 | 星标 |
| --- | --- | --- |
| Google Reader | unread集合双向权威 | 双向权威 |
| Fever | unread 集合双向权威 | saved 集合双向权威 |

政策与协议能力是不同事实。客户端未实现不等于协议做不到；固定上游源码或严格夹具也不等于已验收所有部署。[兼容矩阵](../../../../docs/sync-compat-matrix.md)记录服务端依据，修改政策时必须同时核对实现、说明和行为断言。

所有远端字段落地还受下列共享约束：

- HTTP 前捕获源的 `sync_id/lifecycle_version`，条目内容、GR 未读差分与两协议权威对账在提交时复核仍属同一 active 生命周期。退订/退订再重订使旧响应失效，重建映射保留原源快照，避免清掉已退订保留的收藏。
- HTTP 前捕获本地 `read_version/star_version`。落地仅接受该字段版本仍匹配且没有 pending 意图；字段独立，已推送清队也不能抹去版本。合并命中既有行同样受守卫，只有同一数据库临界区中新插入的行可使用初始值。
- 本地read/unread/star/unstar对源内非空RSS等价组每个真实身份同事务写值、版本与队项；不同源永不闭包。远端每个目标独立确认，不以URL副本或旧CSV扩大目标。组内某字段仍pending时该字段不接受远端旧值。
- 远端精确身份独立合并。组展示未读取任一未读、收藏取任一收藏；不再以另一源read信号覆盖本行own unread。HTTP前版本与当前pending保护仍是接受远端字段的前提。
- 失败不是空集合。GR 读/星标集合按字段隔离，单侧失败不清该侧，另一侧可收敛；Fever unread/saved 任一失败则跳过该段对账并报告错误，已提交的条目变化不凭空回滚。
- 数据变更信号只基于实际提交。GR 逐语句提交时必须立即记录每个成功变更，后续失败不能抹去此前事实；Fever 页事务失败则连同页内信号回滚。当前整轮消费者由[同步运行生命周期](2026-11-05-同步运行生命周期与诊断.md)协调，原“仅 scheduler light 消费”的阶段性限制已失效。

2026-11-05 的完整 unread/starred 回补当时只扩展发现范围，没有改变四格政策；2026-11-09方向变化仍不用发布时间仲裁本地意图，见[GR 权威集合回补](2026-11-13-同步写回与状态一致性.md)。

## Alternatives considered

- **GR 改为双向读权威**：会让远端历史未读重新翻回本地；当时保留 read-wins。代价是远端显式unread不能回流；2026-11-09用户已接受历史未读可能返回并选择双向，旧理由保留为历史取舍。
- **每协议用 trait 隐藏政策**：能分派执行，却仍需读方法才能看清方向；常量表保留可审入口，具体 SQL 仍由应用函数承担。
- **用负数或零表达数据库失败**：调用者容易遗漏特殊值。`Result` 显式表达失败，但仍可能被 `let _ =` 等忽略，类型不能替代调用链审计。
- **只把矩阵写在代码注释中**：用户读者还需要服务端能力与证据范围，故保留独立文档；它不是自动生成契约，存在同步维护成本。

## Consequences

本地 pending 优先意味着长期推送失败时远端字段也会长期不被接受；这是保护用户意图的代价，必须通过队列状态显现。单点政策减少分叉，不保证报告完整：2026-11-06 仍发现认证重试丢失此前变更事实、远端成功后的 SQL 确认失败未进报告，以及完成时间写失败未报错。它们见[同步正确性路线](../../../../docs/roadmap.md#sync-correctness)。

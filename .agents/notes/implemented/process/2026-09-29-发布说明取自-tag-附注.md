# Agent Note: 发布说明取自 tag 附注

Status: implemented

## Problem

annotated tag 与 GitHub Release 曾分别维护说明：tag 记真实变更，web 正文由静态模板产生。双份来源会漂移，用户与维护者看到不同版本描述。

## Decision

新发布以 annotated tag 的 message 为正文来源；release 工作流读取它并在公开前后核对。轻量 tag、空附注、版本不一致或 tag 不属于 main 均失败关闭。2026-11-06 收口手动触发：只接受 tag ref，取消静态回退，使手动恢复与 tag push 遵守同一来源约束。具体操作与用户文案格式只维护在 [docs/release.md](../../../../docs/release.md)。

历史边界有两次明确变化：2026-09-29采用这一来源单点时，旧web正文仍有模板；2026-11-02按用户要求编辑旧Release web正文、保留原tag不动，历史版本因此允许不同。后继[历史文案与提交史边界](2026-11-02-历史文案规范化与提交史边界.md)只取代旧文案格式和“不批量改旧web正文”的选择，不取代后续新发布以tag为源。

不重写历史提交或重打 tag：SHA 是文档、版本与资产的追溯依据。早期曾通过 tag 另起 CI 并轮询同 SHA 历史结果补齐门禁；2026-11-06 改为 Release 调用同一提交的可复用 `ci.yml`，保留完整门禁并直接通过依赖关系阻止失败发布。CI 与构建固定检出该 SHA，构建前及公开前再次核对 tag，main 后来前进不妨碍原草稿恢复。

先构建成功，才创建或恢复同 tag 草稿；仅草稿可替换本版同名安装包及清理未完成上传资产。两包名称、状态、大小与 SHA-256 均核验后才公开；已公开 tag 拒绝重写。固定 tauri-action 已支持同名资产覆盖，旧“构建前清空所有资产”的理由不再成立，纯构建与发布写入分开可避免构建失败先破坏下载。正文与资产最终读回核对；公开请求无成功响应时保留结果未知，先查远端状态。

草稿状态不是开始时的一次授权。恢复元数据、每次资产删除/上传及最后公开前，都按 Release ID 重读并核验 ID、tag 和 `draft === true`；读取失败或不符立即停止。恢复 PATCH 不携带 `draft: true`，避免将外部已公开版本撤回。首次独立审计证实，旧列表快照与一次开始检查无法约束上传期间的外部公开，因此这些边界按每次写入核对。

## Alternatives considered

- 自动从提交标题生成：便于枚举，却不能表达真实用户收益及限制；采用人写附注、工作流搬运核对。
- 手工维护两个新版本说明：容易重现双轨漂移，未采用。
- 接受轻量tag或空正文：缺少可靠说明来源，选择直接失败。
- 当时不批量修旧web正文：减少操作成本；该取舍后来由用户的文案整理要求取代，原理由在固定历史原文中保留。
- 继续轮询同 SHA 历史 CI：重复 tag 运行和旧失败的取舍不清晰，改由同版本可复用 CI 的依赖结果控制发布。
- 直接创建公开 Release 或构建前清空资产：用户可能看到半成品，构建失败还会破坏既有下载；改为构建后草稿验包再公开。

## Consequences

新发布只有一个文本源，漏写附注能在发布前暴露。维护者仍需核对说明与实际改动，tag 机制不能证明功能或安装器正确；历史 web 正文例外继续保留。每次正式 tag 重新跑完整 CI 有时间成本，但失败与构建对象清楚。草稿可恢复，已公开错误必须单独评估处理，不靠重复发布覆盖。

逐次重读有额外 API 请求成本，且 HTTP 检查与写入之间仍没有原子比较更新。全局工作流并发组不能约束 GitHub 页面或其他客户端；发布期间必须避免外部并行修改同 tag Release。该约束与及时停止后续写入共同限定保护范围，不承诺消除所有外部竞态，也不引入分布式锁。

改变说明来源、workflow 读取方式或历史资产策略时重访。当前实现沿 `.github/workflows/release.yml` 与 `tools/release/release-lib.mjs` 核查；本地 API 替身只验证契约与失败路径，真实 CI/发布的当前状态集中在[验收入口](2026-11-03-修复波次的分批、证伪审计与证据门槛.md)。历史原文见[固定基线](https://github.com/Dchean/fluxreader/blob/91ece562d79fd909642cd6d570d636e884b7387e/.agents/notes/implemented/process/2026-09-29-发布说明取自-tag-附注.md)。

# Agent Note: 五调色盘 WCAG 全量收敛落地

Status: implemented

## Problem

rejected 篇（已归档至 archived/feature/2026-11-01-五调色盘WCAG全量批量收敛.md）登记五调色盘 × 深浅色的 WCAG AA 违例挂账（原 230 项关键配对口径下 95 项），浅色 `star-color`/`danger`/`accent-light` 最重，深色残留集中在 tertiary 对 hover/active 瞬态底色。2026-11-02 用户批准全量收敛，本篇记录实际落地。

本轮探针口径：9 个文本/语义 token × 8 个表面（base/sidebar/timeline/reader/elevated/card/card-hover/card-active，半透明逐层合成）× 10 盘位 = 720 配对全算，修前违例 271 配对、涉及 47 个「盘位 × token」组合；复跑为 0。脚本保留在 `tmp/probe-contrast.mjs`（`--solve` 给最小亮度建议），对照表生成器 `tmp/diff-pairs.mjs`，基线快照 `tmp/tokens-baseline.css`（= 479e118）。tmp/ 不入库，探针证据仅本机留存。

## Decision

### 阈值口径（唯一两处非 4.5 例外）

- 深色 `--accent`：3:1。它同时是图标/大字号前景与白字按钮底色，对深色卡片 4.5 与白字压 accent 4.5 在数学上不可同时满足（前者要求 L≥约 0.245，后者要求 L≤约 0.183）。其正文消费不存在（base.css 仅两处 `color: var(--accent)`：命令面板图标与 22px 加粗设备码=大字号），故按图形/大字号 3:1 验收；浅色无冲突，按 4.5 收。
- `--danger` 对 hover/active 瞬态面：3:1。瞬态面上的 danger 消费是图标（卡片悬浮工具栏删除钮等）；常驻面（卡片/浮层/elevated）仍按 4.5。

### 深色（:root 与五个 dark 块）

- 五盘 `--text-tertiary` 上调（保色相）：blue `#828c9c`→`#8891a1`（对卡片 5.02:1；W4 值被 ui-contracts (w4-6) 钉死，断言已按新值更新）、zinc `#7d7d88`→`#8e8e98`、purple `#8a7f9e`→`#958ba7`、emerald `#77977f`→`#7f9d87`、terracotta `#9c8177`→`#a48b82`。
- 五盘 `--bg-card-hover`/`--bg-card-active` 抬升幅度压到原差的 45%（如 blue hover `rgba(45,52,65,.85)`→`rgba(37,43,53,.85)`、active `#242c3b`→`#212732`）：tertiary 若单独上调到能过原 hover 底 4.5，会贴平 secondary（zinc 仅差 ΔL≈0.03），层级消失；压 hover 幅度后 tertiary 只需温和上调。
- :root `--danger` `#d2694d`→`#d47055`（对 elevated 4.45→4.74；代价：白字压 danger 按钮深色下 3.58→约 3.4，该配对本就不达 4.5 且不在本轮口径内）。

### 浅色（五个 light 块 + 新增共享覆盖块）

- 新增 `:root[data-theme="light"]` 语义色覆盖块：`--star-color: #886508`（亮金→深金，对最暗浅底 4.70）、`--sync-ok: #217b3d`、`--feed-error: #a45713`、`--danger: #b74b2e`（取五盘中最暗 bg-base——blue——反推的最严值，全浅色面通用）。
- 五盘 `--text-tertiary` 压深（尺寸由各盘最暗的 bg-base 决定）：blue `#6f7a8c`→`#626c7c`、zinc `#71717a`→`#6c6c75`、purple `#7e7590`→`#726983`、emerald `#6a8076`→`#5e7169`、terracotta `#8a7166`→`#7f685e`。
- 五盘 `--accent`/`--accent-light` 压深：blue accent-light `#4880c8`→`#366db3`（accent 不动）、zinc accent-light `#71717a`→`#6c6c75`、purple accent `#6d68a8`→`#6a65a7` / accent-light `#8781c2`→`#6a63b3`、emerald accent `#35846a`→`#317a62` / accent-light `#4a9d82`→`#387863`、terracotta accent `#b05d42`→`#a6583e` / accent-light `#c67a5f`→`#a6573b`（accent-light 始终保持不暗于 accent 的次序；压深同时改善白字压 accent(-light) 的按钮对比）。
- 五盘 `--bg-card-hover`/`--bg-card-active` 由「明显压暗」收窄为「轻微压暗」（hover = 卡片有效亮度 -0.03、active = -0.015，保色相 tint；如 blue hover `rgba(228,234,246,.95)`→`#ecf0f8`、active `#d6e1f3`→`#eff2f9`）。方向保持压暗不变；若不收窄，tertiary 要过原 active 底 4.5 需压到 L≈0.115——比 secondary（#576274，L≈0.121）还深，层级在数学上不存在。选中态的 affordance 主要由既有 accent ring（`.article-card.active` 的 box-shadow）承担。

## Alternatives considered

### 只调文字、不动 hover/active 底色

深色 zinc tertiary 需 L≥0.308（secondary 仅 0.338）、浅色 tertiary 需压到 secondary 以下：两条路都消灭次级文字层级。否。

### 浅色 hover/active 反向提亮到卡片之上

可让 tertiary 少压深一些，但把浅色「悬浮=压暗」的设计语言整个翻转为「提亮」，观感变化大于收窄压暗幅度。否。

### 深色 accent 强行 4.5

会把白字压 accent 的按钮（.btn-primary、active 导航项等）从现状 3.3-4.9 进一步压到约 3.5——用一个不在口径内的配对回退去换探针列变绿。否，按 3:1 图形口径验收并在此留档。

### 星标保持亮金、按非文字 3:1 验收

WCAG 1.4.11 对图形物件本只需 3:1（`#b8860b` 即可），但用户批准的收敛口径是关键配对 4.5，且星标同时承担「已收藏」状态语义。按 4.5 执行，浅色取 `#886508` 深金保色相。

## Consequences

- 浅色 hover/active 与卡片底的亮度差收窄（原 ΔL≈0.07-0.15 → 0.03/0.015），悬浮感变淡；深色同理（抬升幅度减半）。这是「正文 AA 达标」与「状态差可感知」在近白/近黑底上二选一的取舍，选中态有 accent ring 兜底，悬浮态依赖既有 border/glow 变化。
- 浅色 blue 的 tertiary–secondary 层级差被压缩到最小（#626c7c vs #576274，ΔRGB≈11）：blue 的 bg-base 是五盘最暗，绑定最紧。其余四盘 ΔRGB 17-26。
- 深色白字压 accent/danger 按钮底（3.0-4.4:1）是先于本卡存在的独立问题，数学上无法靠单 token 解决（需 base.css 拆「前景 accent」与「按钮底 accent」两个 token），不在本卡范围，留待后续。
- `docs/roadmap.md` 中 W4 行仍写「dark blue 调至 #828c9c」——历史事实层面正确（W4 当时值），但当前值已再上调，roadmap 不在本卡改动范围内，待下次文档轮同步。

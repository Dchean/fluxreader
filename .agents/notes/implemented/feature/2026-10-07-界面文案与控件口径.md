# Agent Note: 界面术语、控件和必要信息的统一

Status: implemented

## Problem

同一动作多种名字、快捷键格式和相邻控件对齐漂移，会让用户误以为行为不同；设置说明不断增长又挤占可操作空间。文字统一应帮助判断，不能删掉会改变用户决定的风险信息。

## Decision

添加订阅源、同步、刷新使用稳定术语；全量抓取按direct/hybrid真实范围写“全部/本地订阅源”。可见中文标点和快捷键采用一致风格，但这不是禁止URL、代码或机器格式中的ASCII符号。

设置开关复用Switch，下拉复用FluxDropdown，以同一布局约束控制对齐。截断内容保留获取全文的方式，交互项保留可访问名称及键盘动作。不要把“用了统一组件”写成其键盘和读屏已经全部正确的证明。

2026-11-07 对共享下拉补生成的listbox/option ID、combobox的controls与活动项关联。焦点留在触发器，方向键/Home/End只移动活动项，Enter/Space提交；Esc/Tab或焦点离开收起，关闭时去除活动项关系；鼠标选项不抢触发焦点。列表通过portal呈现，不要求DOM物理包含。设置“滚动出列表区域时标为已读”就近补“仅在未读列表中生效”，表达现有前提，不扩展标读行为。

常驻说明以识别对象、状态或后果为限；短句预算是编辑参考，真实渲染宽度仍需检查。危险后果留在操作附近或确认框，不能只藏到hover。布局/折叠/译文显隐等已经可见的成功态减少重复toast，协议细节按需展开，后继边界见[文案精简](../simplification/2026-11-04-用户文案精简与能力矩阵折叠.md)。

## Alternatives considered

扫描所有字符串以强制标点会误报代码、URL和机器文本，当前用审查结合少量行为断言。逐字锁整页文案又会阻止合理微调，因此测试优先锁关键事实和动作，而非永久锁一句措辞。

把长说明全部移到tooltip会使键盘/触屏难发现，尤其不适合数据删除和同步范围。统一词汇能减少歧义，但不能靠文字修复实际状态流转错误。

## Consequences

统一风格降低维护成本；字数、title和组件复用均不能代替溢出、热区或AX验收。2026-11-06字体下拉缺关联与深色小字按钮对比不足的反例保留；2026-11-07候选已补下拉关系，局部对比度取舍见[调色盘记录](2026-11-02-五调色盘WCAG全量收敛落地.md)。真实键盘/AX与主题十盘尚待本批Edge门禁，不能用组件关系断言冒充读屏实听。旧tertiary约4:1的描述已被后续token调整取代，不再作为当前值。

文案变更若触及“谁的数据会删、什么会写回”的承诺，必须对照真实行为；只替换措辞不自动改变产品契约。

## Validation

copyPolicy和组件回归检查必要事实、失败恢复入口、能力折叠及键盘帮助；静态标签少量源级断言只是接线检查。布局与对比需在实际字体、主题和视口中核验。

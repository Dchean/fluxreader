# Agent Note: 2026-11-02 第六轮收尾批次路线（窄域审计 → 两卡并行）

Status: implemented
Archived: 2026-11-06

## Problem

第五轮（v0.18.5 已发布）完成后距用户截止（2026-11-02 08:00，最晚 08:30 收敛）仍有约 2 小时。roadmap 与第五轮审计遗留的 P3 批次中，有六项经全新窄域审计代理复核（前端 Epicurus、Rust Hume）确认仍成立且规格可实施。第六轮需在窗口内完成「审计→修复→复核→tag」整环，批次规模必须压到 CI 单轮可过。

## Decision

两卡并行、写集互不重叠：

1. **前端卡**（Gibbs）：启动抢占期假空态（修法 (b)：Timeline 空态加 `backendReloadsInFlight` 维度——修法 (a) 已被审计证伪：模块计数含自身，:519 处判 `>0` 恒真会把「兜底只关不开」变成「永不关」）；关闭态搜索/重命名输入条件 autoFocus（真实引擎经 Edge CDP 探针证明 inert 生效、无焦点窃取，此项是修 jsdom 通道失真 + 源码级引擎差异保证，规格含修前必红的回归用例）。
2. **Rust 卡**（Sagan）：push_feeds 绑定查找改规范化匹配 + DB 错误可见化（`.ok()` 吞错导致「远端已建、本地永不绑定」窗口）；favicon 与全文提取响应体套 16MiB 界（泛化 read_body_capped，闭合无界内存旁路）；SMTC 浮点入参饱和（消除一次坏数据永久杀死 SMTC 线程的失效模式）。

时间盒内节奏：修复约 1 小时 → 全新代理复核约 30 分钟 → 提交推送 dev CI → main bump → tag `v0.18.6`。tag 后的 ci 门禁与 Release 构建为自动化流程，预计在 08:30 后完成；全部代码调整在 08:00 前完成。

## Alternatives considered

- **订阅 outbox 已消失账号生命周期（身份切换清账）**：Hume 规格完整且判「建议本轮修」，但方案要求显式放弃「换号→回原账号恢复 pending 意图」语义（`outbox.rs:13-15` 头注释与 2026-10-14 执行器 Note 登记的行为），属产品语义变更而非纯缺陷修复。窗口内塞入语义变更 + 文档改写 + 语义测试的 CI 风险不成比例，登记进 roadmap 待产品决策后另立批次。
- **前端修法 (a)（isBackendReloadInFlight 判据）**：被审计证伪，见上。
- **autoFocus 改卸载关闭态面板**：动共享 ModalOverlay（退出动画与焦点还原依赖常驻 DOM），爆炸半径大；条件 autoFocus 一行级且行为逐字不变。
- **favicon 界对齐时顺带处理封面图下载（settings.rs:546-553 content_length 预检 + bytes() 无流式截断）**：审计标注的同族第三处，但无恶意场景实证且改动涉及封面管线语义，仅登记不本轮修。

## Consequences

- 收益：六项 P3（两项前端、四项 Rust 中三项）收口；jsdom 焦点通道失真被修正；「未读集合语义级谎言」「封面图第三旁路」「outbox 生命周期」三项显式登记防重复调查。
- 代价：Rust 行为验证完全依赖 CI；第六轮 tag 的 Release 构建完成时间预计越过 08:30（自动化流程，代码调整在此之前完成）。
- 边界：五调色盘 WCAG 全量收敛仍待用户决策（rejected Note 维持）；401 结构化重构、Bazqux 接入形态、GR 实机验收维持挂账。

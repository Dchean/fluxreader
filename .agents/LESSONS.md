# 防坑教训（真实踩过、仍有效）

格式：**一句话规则 + 错因 + Done right + Seen N×**。Seen 按历史笔记里是否写了复发/回归如实计，没写就 1×。

## 1. 缺字段 ≠ 空集合 — Seen 3×
- **规则**：只有显式 `[]` 才是权威空集，字段缺失一律报错。
- **错因**：Fever 缺字段/短页/map 失败都退化成"空"，进而清本地记录或伪造确认。
- **Done right**：缺字段上抛可辨识错误，让同步报告区分"失败 / 无变化 / 真空集"。→ `src-tauri/src/sync/fever_pull.rs`

## 2. 旧失败不能覆盖新操作 — Seen 3×
- **规则**：判断"是否该写回"要比字段版本 + 在途前沿，不能只比值。
- **错因**：只比值分不出"我没操作"与"我操作后回到同值"，旧请求失败会回滚掉新操作。
- **Done right**：`${id}|${field}` 版本 + Promise 写前沿 + 首次真实属性到达才取基线。→ `src/store/internals.ts`

## 3. 正文旧响应会复活 — Seen 3×
- **规则**：正文缓存必须同时守"记录仍存在""戳未变""命令仍属自己"。
- **错因**：删记录就丢失效戳，只守正文戳时旧回读会继续写入。
- **Done right**：保留 cleared 记录 + contentRevision 戳 + 请求归属三件套。→ `src/store/bodyCache.ts`

## 4. 凭据绝不能往"方便"方向降级 — Seen 2×
- **规则**：加密失败返回错误、不写明文；解密失败返回错误、不当"已解密"。
- **错因**：早期为幂等让 `dpapi:` 前缀明文直接返回，把合法明文误当密文。
- **Done right**：所有非空 setter 输入都当明文加密后再存；读取三态 `AppResult<Option<_>>`。→ `src-tauri/src/credentials.rs`

## 5. 测试替身不能比生产宽松 — Seen 3×
- **规则**：mock/夹具必须绑定真实协议形态，不能用"恰好能过"的假值。
- **错因**：把 `ot` 当 `changed_at`、把 quick_add 当默认幂等，测试绿但线上错。
- **Done right**：替身按真实字段与语义构造，断言打到具体协议形态。→ `src-tauri/tests/`

## 6. 未加载 ≠ 终态 — Seen 2×
- **规则**：空列表要显式 loading；在途计数按 ID，不用全局单布尔。
- **错因**：把"还没加载"当"没有数据"显示空态；全局 `translating` 布尔切换文章后卡死。
- **Done right**：显式 loading 态 + 按 ID 的 `translatingIds`，全局布尔只作展示。→ `src/store/slices/ai.ts`

## 7. 超长会话要主动交接，不要等崩 — Seen 1×
- **规则**：上下文出现反复重读、混淆新旧要求、工具错误增多时，在安全点冻结版本并交接。
- **错因**：曾压缩/resume 冒充换任，前后任同时调度，写集互相覆盖。
- **Done right**：新开独立对话、独审核包、后继签收后才移交唯一调度权。→ 见 `AGENTS.md` 交接节

# 单 agent 模式

当前 agent 完成管理、实现、工具验证和自审。角色是工作阶段，不是多个独立身份。不需要启动 CLI，也不需要注册额外 agent。

1. 以管理角色固定任务目标、范围、验收与门禁，记录基准和预算。
2. 进入实现阶段，只修改任务允许文件，不在修代码时改变验收要求或批准字段。
3. 用真实工具执行验证，保留失败和修复记录。
4. 暂停实现，按 REVIEW 提示词检查最终差异，记录 mode=self_review。
5. 只有 POLICY.review.mode=self_review_allowed 才能以这种审查完成低风险任务。需要独立审查的任务保留为 review/blocked，取得新上下文或用户审查证据。

如果宿主有真正独立的新上下文功能，用户允许后可以用同一个模型做独立审查，但须记录上下文标识和给定输入。无需为了“多 agent”更换模型或扩大并发。

没有文件/终端能力时，本模式只能提供文档和补丁建议，工具验证为 NOT_RUN；不能声称项目已经运行。

# 自定义 harness 接入

不要求工具叫 Codex 或 Claude。管理者询问并记录调用入口、模型/供应商选择、输入输出格式、文件与终端能力、权限回调、取消进程树、超时、持久化及独立审查上下文能力。

实现角色接收同一任务包，返回相同 worker-result；宿主适配器负责转换，不把供应商 session ID 当项目任务身份。先验证最小完整循环，再宣称支持自动推进。

没有结构化输出能力可以由管理者从原始结果提取记录，但要明确这是管理者归一化，保存原件并逐字段核对。不能伪造执行器已返回 schema 结果。

没有进程取消/超时能力时不能承诺无人值守运行上限有效；改为交付任务包或受控人工执行，直到所需能力就绪。后台运行、更多工具权限、外部目的地和并发都需要独立的明确依据。

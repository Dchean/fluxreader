## 一次自查纠正（重要，如实记录）

第一次生成浅色证据时，我用 `updateSettings({themeMode:'light'})` 切换主题，
脚本打印 `theme: dark`，**但我仍把截图存为 `TASK-058-ui-light-failure.png`**。
核对字节后发现它与深色证据**完全相同**：

```text
same bytes as dark evidence? True
```

**处置**：
1. 删除该错误文件；
2. 改为通过**真实 UI 控件**（外观 → ☀️ 浅色模式）切换（`App.tsx:169-180` 的
   `data-theme` 由 React `themeMode` state 驱动，直接改 store 未生效）；
3. **在脚本里加硬校验**：若切换后 `data-theme !== 'light'` 则**中止且不产出文件**，
   杜绝再次生成「标签正确、内容不对」的假证据。

**教训**：生成证据时必须**校验「证据所描述的状态」确实成立**，
而不是先写文件再假定它符合描述。这与本任务之前的宽度误判同源——
**记录的是我以为的状态，而非我验证过的状态**。
